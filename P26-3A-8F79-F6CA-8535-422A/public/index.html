Lista de Tarefas Colaborativa (Shared To-Do)

Construa um gerenciador de tarefas voltado para pequenas equipes de trabalho acadêmico. Após o login via Discord, o usuário pode criar listas de tarefas e compartilhar o código de acesso da lista com colegas de turma, permitindo que múltiplos usuários autenticados visualizem e interajam com os mesmos itens. No Cloudflare D1, o esquema relacional deve contemplar tabelas para usuários, listas, membros da lista e tarefas. Através de JavaScript vanilla, os integrantes podem criar subtarefas, atribuir um responsável (exibindo o avatar do Discord do colega no item) e alterar o status de conclusão, sincronizando o estado com o servidor a cada interação.
